# Global Education & Socioeconomic Analysis

## Objective

This project uses SQL to investigate global education outcomes,
gender disparities, literacy, tertiary enrollment and unemployment.

## Dataset

202 countries
30 variables

## Analytical Process

1. Data Quality & Cleaning
2. Descriptive Analytics
3. Diagnostic Analytics
4. SQL Analysis
5. Strategic Insights

## Key Questions

- What are global out-of-school rates?
- Which countries have the highest unemployment?
- Where are gender disparities strongest?
- Is tertiary enrollment associated with unemployment?
- Where does the education funnel experience the largest drop-off?
- Which countries are the highest priority?
